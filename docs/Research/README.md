## 1. Android-устройства под управлением ESP32

- **Источник:** https://xakep.ru/2026/09/08/android-farm-esp32/
- **Статья:** «Ботоферма. Как создать мини-ферму на Android и ESP32»
- **Дата публикации:** 8 сентября 2026 г.
- **Доступность:** доступна только открытая часть; продолжение и полный код могут быть закрыты подпиской.
- **Краткая выжимка из доступной части:**
  - ESP32-S3 используется как центральный координатор.
  - Android-смартфоны получают задания через Bluetooth Low Energy (BLE).
  - Python-скрипт обеспечивает связь ESP32 с компьютером через Serial.
  - Android-приложения выполняют задания и возвращают результаты.
  - В качестве демонстрационной среды упоминается OWASP Juice Shop.
- **Что изучить позднее:** схема обмена командами и статусами, BLE-протокол, обнаружение и подключение устройств, очередь заданий, обработка ошибок и безопасность.
- **Потенциальная польза:** возможная основа для лабораторного стенда из нескольких Android-устройств; централизованное управление тестовыми устройствами. Для Jarvis/FamilyCore применимость пока не подтверждена.
- **Ограничения:** не переносить концепцию «ботофермы» в продукт без отдельной оценки законности, безопасности и конкретного сценария. Это заметка об архитектурных приёмах, не рекомендация автоматизировать сторонние аккаунты или сервисы.

## 2. git-bug — распределённое управление задачами поверх Git

- **Источник:** https://www.opennet.ru/opennews/art.shtml?num=66330
- **Проект:** https://github.com/git-bug/git-bug
- **Тема заметки:** выпуск git-bug 0.11.0.
- **Краткая выжимка по рассмотренному материалу:**
  - Система управления задачами и ошибками, использующая Git как распределённое хранилище.
  - Возможность вести задачи, обсуждения и комментарии локально, в том числе офлайн, с последующей синхронизацией.
  - Упоминаются CLI, TUI, веб-интерфейс и интеграции с внешними трекерами/платформами.
  - Для программного взаимодействия заявлен GraphQL API.
- **Что проверить позднее:** актуальные возможности версии, формат хранения, модель синхронизации и конфликтов, поддерживаемые интеграции, активность проекта и совместимость с нашим Git-процессом.
- **Потенциальная польза:** изучить как вариант локального журнала задач, дефектов, комментариев и технических решений для разработки Jarvis.
- **Статус:** не внедрено и не выбрано. Сначала сравнить с GitHub Issues/Projects и текущим процессом разработки.
