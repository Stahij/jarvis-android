# Gemini CLI — агент для работы с кодом из терминала

Источник: https://thecode.media/gemini-cli-ustanovka-nastrojka-claude-code/  
Обновлено в статье: 21 октября 2026 года.

## Что это
Gemini CLI — открытый терминальный агент Google (Apache 2.0), который получает контекст из папки проекта, читает и изменяет файлы, запускает команды и тесты. Модель при этом работает через облачный сервис, а не локально.

## Полезные возможности
- `GEMINI.md`: постоянные инструкции проекта и правила работы.
- Checkpointing, `/rewind`, `/restore`: контрольные точки и откат локальных изменений.
- Plan Mode: сначала исследование и план, затем правки.
- Policy engine: разрешать, запрещать или требовать подтверждение для вызовов инструментов.
- `.geminiignore`: исключения для чтения/поиска инструментами агента; это не полноценная защита секретов.
- MCP, расширения, skills, hooks и субагенты.
- Headless-режим с JSON-ответом: можно использовать для автоматизированного ревью diff.
- Интеграция с GitHub Actions.

## Доступ и ограничения
По статье, с 18 июня 2026 года Google прекратил потребительскую авторизацию Gemini CLI через личные аккаунты, включая бесплатный уровень и AI Pro/Ultra. Варианты доступа: Gemini API, Vertex AI или корпоративный Code Assist. Установка CLI бесплатна, но использование облачной модели может тарифицироваться и ограничиваться квотами.

Статья указывает Node.js 20+ и поддерживаемые настольные ОС Linux/macOS/Windows. Поддержка Android/Termux в ней не заявлена; не считать совместимость с Termux подтверждённой.

## Применение в наших проектах
Кандидат на роль дополнительного агента для независимого анализа PR, ревью staged diff и выполнения тестов. Не заменяет GitHub Actions и не должен самостоятельно выполнять merge или отправлять изменения.

Полезные практики для Jarvis:
1. Сначала Plan Mode и согласование списка файлов.
2. Изолированная ветка и сохранённые Git-изменения до запуска агента.
3. Подтверждение Git-команд и запрет опасных операций по умолчанию.
4. Автоматические тесты после правок; человек проверяет diff и принимает решение о merge.
5. Не передавать секреты в контекст; хранить ключи вне репозитория и использовать секреты CI.

## Статус
Исследовательская находка. Не установлено и не внедрено. Перед экспериментом отдельно проверить доступность Gemini API и фактическую стоимость на тестовой задаче.
