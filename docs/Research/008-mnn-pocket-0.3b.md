# MNN-Pocket-0.3B — сверхкомпактная локальная модель Alibaba

Источник новости: https://club.dns-shop.ru/digest/188401-alibaba-predstavila-ii-model-na-300-mln-parametrov-173-mb-i-3/  
Официальная модель: https://huggingface.co/taobao-mnn/MNN-Pocket-0.3B  
Android/iOS INT4-сборка: https://huggingface.co/taobao-mnn/MNN-Pocket-0.3B-MNN  
GGUF для llama.cpp: https://huggingface.co/taobao-mnn/MNN-Pocket-0.3B-GGUF  
Движок: https://github.com/alibaba/MNN  
Дата релиза: 4 ноября 2026 года.

## Подтверждённые характеристики
- Около 300 млн параметров.
- Apache License 2.0.
- Специализированная MNN INT4 W4A16 QAT-сборка занимает около 173 MB (171 MB веса плюс служебные файлы).
- Поддерживается контекст до 32K токенов.
- Архитектура: 28 слоёв, hidden size 896, GQA с 2 KV heads.
- Официально заявленные языки: китайский и английский.
- Предназначена для локальных мобильных помощников, извлечения данных и лёгких агентных сценариев.
- Не рекомендуется для сложной математики и длительной генерации кода.

## Производительность — цифры разработчика
- iPhone 18 Pro: около 350 токенов/с decode.
- iPad Pro M5, Metal: до 466 токенов/с.
- Snapdragon 8 Gen 5: до 251 токена/с на CPU при тестовом контексте 512 токенов.
- Для Snapdragon 8 Gen 5 в опубликованной таблице OpenCL показатель ниже CPU; цифры зависят от backend и условий.
- Заявления об энергопотреблении следует считать результатами лабораторных тестов команды, а не гарантией для других устройств.

## Форматы и запуск
Доступны разные артефакты, которые нельзя путать:
- MNN INT4 W4A16 QAT: около 173 MB; целевой runtime — MNN, есть Android/iOS/HarmonyOS.
- GGUF Q4_1: около 192 MB; совместимый runtime — llama.cpp.
- GGUF Q8_0: около 387 MB.
- GGUF F16: около 726 MB.
GGUF-модель можно тестировать через llama.cpp. Важно явно выбирать Q4_1; автоматический выбор в инструкции может взять Q8_0. MNN INT4-формат не является GGUF и требует MNN runtime. Для MNN-артефакта версия runtime должна соответствовать семейству ревизии экспорта.

## Значение для Jarvis
Это очень интересный кандидат на дополнительную сверхлёгкую модель:
- быстрые короткие ответы и классификация команд;
- маршрутизация запросов и извлечение простых данных;
- простые локальные действия с ограниченным контекстом;
- возможно, фоновый быстрый помощник рядом с более крупной моделью.

Не считать заменой текущей основной модели Qwen2.5-3B-Instruct Q4_K_M: 0.3B-модель существенно меньше, а заявленные тесты сосредоточены на китайском и английском. Русский язык и качество на наших реальных задачах необходимо отдельно проверить.

## Применимость к устройству пользователя
Текущее тестовое устройство: Xiaomi 2209116AG, Android 13, Snapdragon 732G, 8 GB RAM (плюс виртуальное расширение). В опубликованных результатах нет теста Snapdragon 732G, поэтому нельзя переносить показатели 251 tok/s со Snapdragon 8 Gen 5 на это устройство.
Практический путь проверки:
1. Сначала загрузить GGUF Q4_1 (около 192 MB) в уже используемый llama.cpp/llama-server.
2. Проверить совместимость с актуальной версией llama.cpp и корректный ChatML-шаблон.
3. Измерить загрузку, RAM, prefill/decode, нагрев и батарею на Snapdragon 732G.
4. Прогнать одинаковый набор русскоязычных задач вместе с Qwen2.5-3B Q4_K_M.
5. Только если качество и скорость приемлемы — рассмотреть отдельный MNN Android runtime как альтернативный backend.

## Статус
Сильный кандидат для экспериментального теста, но не замена основной модели и не утверждённая зависимость. Не внедрено; APK, код и настройки сборки Jarvis не менялись.
