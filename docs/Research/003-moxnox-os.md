# Moxnox 1.0 — самостоятельная ОС с NT-подобными интерфейсами

Источник: https://www.opennet.ru/opennews/art.shtml?num=66552  
Дата новости: 26 октября 2026 года.

## Кратко
Moxnox — хобби-операционная система Марка Хармстоуна, разрабатываемая с 2022 года. Ориентируется на архитектурные идеи Windows NT, совместима с частью POSIX и использует Btrfs. Проект достиг self-hosting.

- Около 130 тыс. строк C++.
- Архитектуры: x86-64-v3 и ARMv8.1; заявлена работа на Raspberry Pi 5.
- Реализованы 642 из примерно 1200 функций POSIX 2024.
- Поддерживаются bash, gcc (amd64), git, Python, Rust, OpenSSH, OpenSSL и другие инструменты.
- Исполняемый формат PE; библиотеки DLL, программы EXE.
- Лицензии: GPL (ядро и базовые программы), LGPL (библиотеки), MIT (модули).

## Ограничения
Пока доступен только консольный режим. Нет многопользовательского окружения и механизмов безопасности; не поддерживаются Windows-программы. Полноценный GUI заявлен как будущая работа.

## Возможная польза для наших проектов
Пока только исследовательский материал. Для Jarvis практической готовой зависимости здесь нет. Полезные темы для изучения:
- ARM-поддержка и переносимость системного ПО;
- self-hosting и воспроизводимая сборка;
- разделение системных интерфейсов и реализаций;
- лицензирование компонентов.

Не использовать как основу Android-архитектуры без отдельного технического обоснования. Не внедрено.
