# OutWiker 4.1 — файловая база заметок

- **Источник:** https://opennet.ru/opennews/art.shtml?num=66349
- **Проект:** https://github.com/Jenyay/outwiker
- **Дата новости:** 28 сентября 2026 г.
- **Краткая выжимка:** OutWiker хранит заметки в виде каталогов с текстовыми файлами; к заметке можно прикреплять произвольное количество файлов. Поддерживаются HTML и wiki-разметка, Markdown — через плагин. Плагины добавляют, в частности, LaTeX и блоки кода с подсветкой синтаксиса. В версии 4.1 добавлены создание заметки из выделенного текста, открытие новой заметки во вкладке, сортировка по датам создания/изменения, настройка цветов облака тегов и сохранение позиции прокрутки. Программа написана на Python/wxPython, лицензия GPLv3; доступны сборки Linux (Snap/Flatpak) и Windows.
- **Потенциальная польза:** не готовая зависимость для Jarvis, а пример организации базы знаний: отдельные текстовые заметки в каталогах, вложения, теги и расширение плагинами.
- **Что изучить позднее:** структуру хранения и удобство навигации; сравнить подход с нашим `docs/Research/` и вариантами локальной базы знаний.
- **Ограничения:** в новости не заявлена мобильная версия; не считать OutWiker подходящим Android-компонентом без отдельной проверки.
- **Статус:** только исследовательская заметка, внедрение не планировалось.
