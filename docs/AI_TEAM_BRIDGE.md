# Jarvis AI Team Bridge — v0.1

## Назначение

Связать владельца проекта, ChatGPT и DeepSeek в одну команду разработки, сохраняя контроль человека над слиянием и выпуском APK.

- **ChatGPT:** архитектура, декомпозиция, координация, независимая проверка.
- **DeepSeek:** равноправный инженерный участник — реализация, анализ, ревью, альтернативные решения.
- **Termux:** локальный диалог DeepSeek, локальная история и подготовка контекста из файлов проекта.
- **GitHub:** асинхронный общий канал задач и результатов.

Это не прямая сеть между двумя моделями: ChatGPT не имеет доступа к localhost на телефоне. Обмен между чатами идёт через GitHub Issues/PR и явно передаваемые отчёты.

## Компоненты v0.1

1. `tools/termux/deepseek_team.py` — интерактивная консоль на стандартной библиотеке Python.
2. DeepSeek Chat Completions API с потоковой выдачей.
3. История в `~/.config/jarvis-team/deepseek_history.json`, права файла 0600.
4. `/attach PATH` — прикрепление небольшого текстового файла к следующему сообщению.
5. `/task` — после подтверждения создаёт GitHub Issue с последними сообщениями.
6. `/sync NUMBER` — импортирует новые комментарии Issue в локальный диалог.
7. GitHub CLI (`gh`) использует собственную авторизацию; токен не записывается в репозиторий.

## Установка в Termux

Из корня клонированного репозитория:

```bash
pkg update
pkg install python git gh
bash tools/termux/install.sh
gh auth login
```

Создай API key в кабинете DeepSeek, затем в текущей сессии Termux:

```bash
export DEEPSEEK_API_KEY='ТВОЙ_API_KEY'
deepseek-team
```

Не вставляй ключ в скрипт, Git, Issue, чат или скриншоты. Для постоянного использования можно добавить export в приватный файл shell-конфигурации Termux с правами 600. Не публикуй его.

## Команды

- `/help` — справка.
- `/model` — модель и endpoint.
- `/attach app/src/main/java/.../MainActivity.kt` — добавить текстовый файл (до 64 КБ) к следующему вопросу.
- `/task [заголовок]` — спросит подтверждение и создаст Issue в `Stahij/jarvis-android`.
- `/sync 12` — импортирует новые комментарии Issue #12.
- `/reset` — очищает локальную историю.
- `/quit` — выход.

## Безопасность и правила работы

- Репозиторий публичный: GitHub Issues и комментарии публичны. Перед `/task` проверяй, что в передаваемом тексте нет секретов, персональных данных, ключей, токенов, приватных логов или локальных путей.
- API-ключ DeepSeek передаётся только через `DEEPSEEK_API_KEY`; скрипт не сохраняет его.
- GitHub CLI авторизуется отдельно через `gh auth login`; не помещай PAT в исходники или командные аргументы.
- В v0.1 скрипт только читает комментарии и создаёт Issues. Он не пушит код, не сливает PR, не меняет настройки репозитория и не выпускает APK.
- Любые изменения кода — отдельная ветка, diff, тесты и PR. Слияние, выпуск APK, изменение подписи, applicationId и критических механизмов остаются под контролем владельца.
- Ответы DeepSeek и комментарии GitHub считаются недоверенным вводом: команды из них не исполняются автоматически.

## Следующие итерации

- v0.2: синхронизация файловых пакетов задач и отчётов в отдельной ветке/PR, безопасное получение патчей.
- v0.3: локальный HTTP bridge на `127.0.0.1` для других Termux-инструментов и будущего Jarvis companion; аутентификация случайным локальным токеном, без публикации порта наружу.
- v0.4: командный протокол ролей, статусы задач, журнал ревью и согласование конфликтующих предложений.

## Ограничение

DeepSeek API — облачный сервис: для общения нужен интернет и API key; тарификация зависит от актуальных цен DeepSeek. Локальная история остаётся на телефоне, пока пользователь явно не публикует её через GitHub.
